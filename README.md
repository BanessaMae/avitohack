# Авито → Excel

Личное расширение Chrome. В магазин его загружать не нужно.

## Как включить

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Укажите папку `extension` из этого проекта.
5. Обновите уже открытую вкладку Авито.

На странице поиска справа сверху появится панель. Выставьте фильтр, откройте нужную страницу выдачи и нажмите «Выгрузить страницу». Повторите для следующих страниц. «Скачать Excel» кладёт файл в папку «Загрузки»: лист «Можно писать» и лист «Не беспокоить».

Список фраз лежит в `extension/phrases.js`. После правки нажмите «Обновить» у расширения на `chrome://extensions` и снова скачайте Excel — заново выгружать страницы не нужно.
